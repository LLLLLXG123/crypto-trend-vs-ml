# 阶段 1：OKX 连接与数据 · 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 打通 OKX：把 4 个品种从 2022-03-01 至今的 1 小时 K 线和资金费率增量同步到本地，并生成数据质量报告；拿到模拟盘密钥后，能在模拟盘上下单、按订单编号查单和撤单。

**Architecture:** 两个连接分开：「行情连接」走真实市场、不用密钥；「交易连接」只负责模拟盘下单和查账户。数据层是一组小模块：转换（candles）→ 存储（store，Parquet、原子写）→ 下载（history、funding）→ 质量报告（quality）→ 编排（sync）。所有交易所调用都通过传入的 client 对象，测试用假的 client，不联网、不需要密钥。

**Tech Stack:** Python 3.11、ccxt 4.5.85、pandas 3.0.6、pyarrow 26.0.0、PyYAML、python-dotenv、requests、pytest。

**Spec:** `docs/2026-10-12-加密货币量化平台-总体设计.md`（主要是 7.1、7.2、7.5 节；本计划只做阶段 1）

**本计划的代码已经验证过（2026-10-12）**：计划里的全部文件在临时目录用 conda 环境 `bitcoin` 跑通了 95 个测试；也用真实的 OKX 接口完整同步过 BTC 永续：40,476 根 K 线，没有缺失和异常价格；5,060 条资金费率，没有缺口，有 2 次非整点结算。首次同步用时 106 秒，第二次 1.6 秒，两次结果相同。

## Global Constraints

- 运行环境：本地是 conda 环境 `bitcoin`（Python 3.11.17）。代码只用 3.11 的语法，服务器上的 3.12 也要能跑。
- 依赖版本锁定在 `requirements.txt`：ccxt==4.5.85、pandas==3.0.6、numpy==2.4.6、pyarrow==26.0.0、python-dotenv==1.2.4、PyYAML==6.0.3、requests==2.34.2、pytest==9.1.1。
- 时间一律用 UTC。K 线按收盘时间标记：标为 13:00 的 K 线覆盖 12:00–13:00。DataFrame 里的时间列类型固定为 `datetime64[ms, UTC]`。
- 数量一律用币的数量。永续合约的"张"只在 `bitquant/broker/okx.py` 内部换算。
- 品种用 ccxt 的统一写法：现货写 `BTC/USDT`，永续写 `BTC/USDT:USDT`。本期品种是 BTC/USDT、ETH/USDT、BTC/USDT:USDT、ETH/USDT:USDT；频率 1h；history_start 是 2022-03-01；capital_usdt 是 10000。
- 行情连接不开模拟盘开关、不用密钥。交易连接在 demo 模式下开模拟盘开关。live 模式本期一律拒绝，抛 `LiveModeDisabled`。
- 密钥只从环境变量读：`OKX_DEMO_API_KEY`、`OKX_DEMO_SECRET`、`OKX_DEMO_PASSPHRASE`，放在 `config/.env` 里。这个文件不入 git，也不能发到对话里。
- 订单编号只含字母和数字，最长 32 位，由"策略 + 品种 + 信号时间"生成。
- 永续用逐仓（`marginMode="isolated"`）、3 倍杠杆、单向持仓（net_mode）。
- 存储：每个品种一个 Parquet 文件。先写 `.tmp` 文件，再用 `os.replace` 替换。发现缺口只记录，不补。
- 测试不联网，也不需要密钥。需要联网的验证只放在 `scripts/` 的脚本里，手动运行。
- 每个模块先写测试再实现。注释和面向用户的文字用中文，写得简洁。

## Review Focus

设计文档没有逐条写明、但最容易在真实使用中出问题的五种情况。每一条都已经在对应任务里补了测试：

1. **同步到一半断网**（`ccxt.NetworkError`）：已经下载的页不能丢，文件也不能损坏，重新运行时要从断点接着下 → 任务 7 `test_network_failure_keeps_downloaded_pages_and_resumes`
2. **整点刚过不到 1 分钟就运行同步**：交易所可能还没定稿刚收盘的那根 K 线，这时不能收录它 → 任务 10 `test_sync_end_skips_bar_closed_less_than_a_minute_ago`；实时取数靠交易所的确认标记判断 → 任务 9 `test_retries_until_confirmed`
3. **在配置里新增品种后再同步**：只下载新品种，已有品种的文件不能被重写 → 任务 10 `test_new_symbol_only_downloads_itself`
4. **官网资金费率文件列表为空，或接口暂时没有数据**：同步不能中断，质量报告要标出"起点晚于 history_start" → 任务 8 `test_sync_survives_empty_file_list`、任务 6 `test_funding_report_on_time_and_empty`
5. **模拟盘赠送的币，余额不够最小下单量（粉尘）**：初始化脚本跳过并说明原因，不能报错退出 → 任务 12 `test_liquidation_sells_spot_and_skips_dust`

另外，实测发现 OKX 历史上有过非整点的资金费结算（2022-12-18 18:54）。质量报告把这种情况单独列为 `off_schedule`，不算作缺口 → 任务 6 `test_funding_off_schedule_is_listed_but_not_counted_as_gap`。

```python
"""读取 config/settings.yaml 和环境变量里的密钥，并做基本校验。"""

from __future__ import annotations

import datetime as dt
import os
from dataclasses import dataclass
from pathlib import Path

import yaml

SUPPORTED_MODES = ("demo", "live")
SUPPORTED_TIMEFRAMES = ("1h",)
DEMO_KEY_NAMES = ("OKX_DEMO_API_KEY", "OKX_DEMO_SECRET", "OKX_DEMO_PASSPHRASE")


class ConfigError(ValueError):
    """配置内容不合法。"""


class LiveModeDisabled(RuntimeError):
    """本期不允许实盘模式（设计文档 7.2）。"""


@dataclass(frozen=True)
class Settings:
    mode: str
    proxy: str | None
    spot: tuple[str, ...]
    swap: tuple[str, ...]
    timeframe: str
    history_start: dt.date
    capital_usdt: float
    data_dir: Path

    @property
    def symbols(self) -> tuple[str, ...]:
        return self.spot + self.swap


@dataclass(frozen=True)
class Credentials:
    api_key: str
    secret: str
    passphrase: str


def load_settings(path: str | Path = "config/settings.yaml") -> Settings:
    raw = yaml.safe_load(Path(path).read_text(encoding="utf-8")) or {}
    exchange = raw.get("exchange") or {}

    mode = exchange.get("mode", "demo")
    if mode not in SUPPORTED_MODES:
        raise ConfigError(f"exchange.mode 只能是 demo 或 live，当前是 {mode!r}")

    timeframe = raw.get("timeframe", "1h")
    if timeframe not in SUPPORTED_TIMEFRAMES:
        raise ConfigError(f"timeframe 目前只支持 1h，当前是 {timeframe!r}")

    symbols = raw.get("symbols") or {}
    spot = tuple(symbols.get("spot") or ())
    swap = tuple(symbols.get("swap") or ())
    if not spot and not swap:
        raise ConfigError("symbols 至少要配置一个品种")
    for s in spot:
        if ":" in s:
            raise ConfigError(f"现货品种不能带结算币后缀：{s}")
    for s in swap:
        if ":" not in s:
            raise ConfigError(f"永续品种要写成 BTC/USDT:USDT 的格式：{s}")

    try:
        history_start = dt.date.fromisoformat(str(raw.get("history_start", "2022-03-01")))
    except ValueError as exc:
        raise ConfigError(f"history_start 要写成 2022-03-01 的格式：{exc}") from exc

    capital = float(raw.get("capital_usdt", 0))
    if capital <= 0:
        raise ConfigError("capital_usdt 必须大于 0")

    return Settings(
        mode=mode,
        proxy=exchange.get("proxy") or None,
        spot=spot,
        swap=swap,
        timeframe=timeframe,
        history_start=history_start,
        capital_usdt=capital,
        data_dir=Path(raw.get("data_dir", "data")),
    )


def load_credentials(mode: str, env: dict[str, str] | None = None) -> Credentials:
    if mode == "live":
        raise LiveModeDisabled("本期不允许实盘模式，live 要到阶段 5 才开放")
    if mode != "demo":
        raise ConfigError(f"未知模式 {mode!r}")
    env = dict(os.environ) if env is None else env
    missing = [name for name in DEMO_KEY_NAMES if not env.get(name)]
    if missing:
        raise ConfigError(
            "缺少模拟盘密钥：" + "、".join(missing) + "（写进 config/.env，参考 config/.env.example）"
        )
    return Credentials(*(env[name] for name in DEMO_KEY_NAMES))
```

```python
"""时间工具：全项目一律用 UTC，时间列统一为 datetime64[ms, UTC]。"""

from __future__ import annotations

import time

import pandas as pd

HOUR_MS = 3_600_000
DAY_MS = 24 * HOUR_MS
TIME_DTYPE = "datetime64[ms, UTC]"
_EPOCH = pd.Timestamp("1970-01-01", tz="UTC")


def now_ms() -> int:
    return int(time.time() * 1000)


def floor_hour_ms(ms: int) -> int:
    return ms - ms % HOUR_MS


def ms_to_utc(values) -> pd.Series:
    """毫秒整数 → datetime64[ms, UTC] 的 Series（保留传入 Series 的索引）。"""
    ints = pd.Series(values, dtype="int64")
    return pd.to_datetime(ints, unit="ms", utc=True).astype(TIME_DTYPE)


def to_ms(value) -> int:
    """Timestamp / date / ISO 字符串 → 毫秒整数；不带时区的按 UTC 处理。"""
    ts = pd.Timestamp(value)
    ts = ts.tz_localize("UTC") if ts.tzinfo is None else ts.tz_convert("UTC")
    return int((ts - _EPOCH) // pd.Timedelta(milliseconds=1))
```

```python
"""品种命名：ccxt 统一符号 ↔ OKX instId ↔ 文件名 ↔ 订单编号里的短代码。

现货写成 BTC/USDT，USDT 本位永续写成 BTC/USDT:USDT（ccxt 的写法）。
"""

from __future__ import annotations

import re

_PATTERN = re.compile(r"^([A-Z0-9]+)/([A-Z0-9]+)(?::([A-Z0-9]+))?$")


def parse(symbol: str) -> tuple[str, str, str | None]:
    m = _PATTERN.match(symbol)
    if not m:
        raise ValueError(f"品种格式不对：{symbol!r}，应为 BTC/USDT 或 BTC/USDT:USDT")
    base, quote, settle = m.groups()
    if settle is not None and settle != quote:
        raise ValueError(f"只支持 USDT 本位的线性永续：{symbol!r}")
    return base, quote, settle


def is_swap(symbol: str) -> bool:
    return parse(symbol)[2] is not None


def base_ccy(symbol: str) -> str:
    return parse(symbol)[0]


def inst_id(symbol: str) -> str:
    base, quote, settle = parse(symbol)
    return f"{base}-{quote}-SWAP" if settle else f"{base}-{quote}"


def inst_family(symbol: str) -> str:
    base, quote, settle = parse(symbol)
    if not settle:
        raise ValueError(f"现货没有 instFamily：{symbol!r}")
    return f"{base}-{quote}"


def file_stem(symbol: str) -> str:
    return inst_id(symbol)


def compact_code(symbol: str) -> str:
    base, quote, settle = parse(symbol)
    return (base + quote).lower() + ("p" if settle else "")
```

```python
"""全系统共用的数据结构（设计文档 7.1）。数量一律是币的数量。"""

from __future__ import annotations

import re
from dataclasses import dataclass

import pandas as pd

from bitquant.symbols import compact_code

SIDES = ("buy", "sell")
KINDS = ("spot", "swap")
_NOT_ALNUM = re.compile(r"[^a-z0-9]")


@dataclass(frozen=True)
class MarketRule:
    symbol: str
    inst_id: str
    kind: str              # "spot" / "swap"
    amount_step: float     # 数量最小变动（币）
    min_amount: float      # 最小下单量（币）
    contract_size: float   # 每张合约对应的币数，现货为 1.0
    price_tick: float      # 价格最小变动

    def __post_init__(self):
        if self.kind not in KINDS:
            raise ValueError(f"kind 只能是 spot 或 swap：{self.kind!r}")


@dataclass(frozen=True)
class Order:
    client_id: str
    symbol: str
    side: str
    qty: float                 # 币的数量，必须大于 0
    signal_time: pd.Timestamp  # 触发它的那根 K 线的收盘时间（UTC）

    def __post_init__(self):
        if self.side not in SIDES:
            raise ValueError(f"side 只能是 buy 或 sell：{self.side!r}")
        if not self.qty > 0:
            raise ValueError(f"qty 必须大于 0：{self.qty!r}")


@dataclass(frozen=True)
class Fill:
    client_id: str
    symbol: str
    side: str
    qty: float         # 成交数量（币）
    price: float       # 成交均价
    fee_usdt: float    # 手续费折成 USDT，付出为正
    ts: pd.Timestamp


def client_order_id(strategy: str, symbol: str, signal_time, tag: str = "") -> str:
    """策略 + 品种 + 信号时间 → OKX 订单编号（只含字母数字，最长 32 位）。

    同一个信号在回测和模拟盘里编号相同；程序重启后也能按编号判断这一单是否已经下过。
    """
    name = _NOT_ALNUM.sub("", strategy.lower())[:10]
    if not name:
        raise ValueError("策略名至少要有一个字母或数字")
    if tag and not (tag.isascii() and tag.isalnum()):
        raise ValueError(f"tag 只能是字母数字：{tag!r}")
    ts = pd.Timestamp(signal_time)
    if ts.tzinfo is None:
        raise ValueError("signal_time 必须带时区（UTC）")
    ts = ts.tz_convert("UTC")
    if ts != ts.floor("h"):
        raise ValueError(f"signal_time 必须是整点：{ts}")
    cid = f"{name}{compact_code(symbol)}{ts:%y%m%d%H}{tag.lower()}"
    if len(cid) > 32:
        raise ValueError(f"订单编号超过 32 位：{cid}")
    return cid
```

```python
"""交易规则快照：最小下单量、数量步长、合约面值（设计文档 7.1、7.2）。

ccxt 的 OKX 用"步长"表示精度（precisionMode = TICK_SIZE）。永续的数量单位是"张"，
这里统一换算成币的数量，回测和模拟盘共用同一份快照文件。
"""

from __future__ import annotations

import json
from dataclasses import asdict
from decimal import ROUND_FLOOR, Decimal
from pathlib import Path

from bitquant.models import MarketRule

TICK_SIZE = 4  # 等于 ccxt.TICK_SIZE


def _mul(a, b) -> float:
    return float(Decimal(str(a)) * Decimal(str(b)))


def rules_from_markets(markets: dict, symbols, precision_mode: int = TICK_SIZE) -> dict[str, MarketRule]:
    if precision_mode != TICK_SIZE:
        raise ValueError(f"只支持步长精度（TICK_SIZE），当前 precisionMode={precision_mode}")
    rules = {}
    for symbol in symbols:
        if symbol not in markets:
            raise KeyError(f"交易所没有这个品种：{symbol}")
        m = markets[symbol]
        step = m["precision"]["amount"]
        minimum = m["limits"]["amount"]["min"]
        tick = float(m["precision"]["price"])
        if m.get("swap"):
            size = m["contractSize"]
            rules[symbol] = MarketRule(symbol, m["id"], "swap", _mul(step, size), _mul(minimum, size), float(size), tick)
        elif m.get("spot"):
            rules[symbol] = MarketRule(symbol, m["id"], "spot", float(step), float(minimum), 1.0, tick)
        else:
            raise ValueError(f"只支持现货和永续：{symbol}")
    return rules


def floor_to_step(qty: float, step: float) -> float:
    """向下取整到步长的整数倍（用 Decimal，避免浮点误差）。"""
    q, s = Decimal(str(qty)), Decimal(str(step))
    return float((q / s).to_integral_value(rounding=ROUND_FLOOR) * s)


def save_rules(rules: dict[str, MarketRule], path: str | Path) -> None:
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    payload = {s: asdict(r) for s, r in sorted(rules.items())}
    path.write_text(json.dumps(payload, ensure_ascii=False, indent=2), encoding="utf-8")


def load_rules(path: str | Path) -> dict[str, MarketRule]:
    payload = json.loads(Path(path).read_text(encoding="utf-8"))
    return {s: MarketRule(**fields) for s, fields in payload.items()}


def fetch_and_save_rules(client, symbols, path: str | Path) -> dict[str, MarketRule]:
    client.load_markets()
    rules = rules_from_markets(client.markets, symbols, client.precisionMode)
    save_rules(rules, path)
    return rules
```

```python
行情连接：走真实市场，不用密钥，也不开模拟盘开关。OKX 模拟盘的 K 线和资金费率是它自己的一套

import ccxt

from bitquant.config import Credentials, LiveModeDisabled, Settings

            "enableRateLimit": True,
            "timeout": TIMEOUT_MS,
        }
    )
    client.set_sandbox_mode(True)
    _apply_proxy(client, settings.proxy)
```

```python
"""本地存储：每个品种一个 Parquet 文件（设计文档 7.2）。

写入时先写临时文件再改名，读的一方不会读到写了一半的文件。
"""

from __future__ import annotations

import os
from pathlib import Path

import pandas as pd

from bitquant.symbols import file_stem
from bitquant.timeutil import TIME_DTYPE

CANDLE_COLUMNS = ["close_time", "open", "high", "low", "close", "volume"]
FUNDING_COLUMNS = ["funding_time", "rate"]


def candles_path(data_dir: str | Path, symbol: str) -> Path:
    return Path(data_dir) / "candles" / f"{file_stem(symbol)}_1h.parquet"


def funding_path(data_dir: str | Path, symbol: str) -> Path:
    return Path(data_dir) / "funding" / f"{file_stem(symbol)}.parquet"


def normalize(df: pd.DataFrame, columns: list[str]) -> pd.DataFrame:
    """只保留指定列：第一列是时间（datetime64[ms, UTC]），其余是 float64。"""
    time_col = columns[0]
    out = df.loc[:, columns].copy()
    out[time_col] = pd.to_datetime(out[time_col], utc=True).astype(TIME_DTYPE)
    for col in columns[1:]:
        out[col] = out[col].astype("float64")
    return out.reset_index(drop=True)


def empty_frame(columns: list[str]) -> pd.DataFrame:
    return normalize(pd.DataFrame({c: [] for c in columns}), columns)


def read_frame(path: str | Path, columns: list[str]) -> pd.DataFrame:
    path = Path(path)
    if not path.exists():
        return empty_frame(columns)
    return normalize(pd.read_parquet(path), columns)


def merge_frames(old: pd.DataFrame, new: pd.DataFrame, columns: list[str]) -> pd.DataFrame:
    """合并新旧数据：按时间去重（同一时间以新数据为准），按时间排序。"""
    time_col = columns[0]
    parts = [normalize(f, columns) for f in (old, new) if not f.empty]
    if not parts:
        return empty_frame(columns)
    merged = pd.concat(parts, ignore_index=True)
    merged = merged.drop_duplicates(subset=time_col, keep="last")
    return merged.sort_values(time_col).reset_index(drop=True)


def write_atomic(df: pd.DataFrame, path: str | Path) -> None:
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_name(path.name + ".tmp")
    df.to_parquet(tmp, index=False)
    os.replace(tmp, path)
```

```python
"""把 OKX / ccxt 的 K 线转成项目统一格式（设计文档 7.1、7.2）。

交易所用开盘时间标记 K 线；本项目用收盘时间标记：标为 13:00 的 K 线覆盖 12:00–13:00。
"""

from __future__ import annotations

import pandas as pd

from bitquant.data.store import CANDLE_COLUMNS, empty_frame, normalize
from bitquant.timeutil import HOUR_MS, ms_to_utc


def ohlcv_to_frame(rows: list[list], now_ms: int, timeframe_ms: int = HOUR_MS) -> pd.DataFrame:
    """ccxt 的 [开盘时间, 开, 高, 低, 收, 量] → 按收盘时间标记的 DataFrame。

    收盘时间晚于 now_ms 的 K 线（还没收盘）一律丢掉。
    """
    if not rows:
        return empty_frame(CANDLE_COLUMNS)
    raw = pd.DataFrame(rows, columns=["open_ms", "open", "high", "low", "close", "volume"])
    raw["close_ms"] = raw["open_ms"].astype("int64") + timeframe_ms
    raw = raw[raw["close_ms"] <= now_ms].reset_index(drop=True)
    if raw.empty:
        return empty_frame(CANDLE_COLUMNS)
    raw["close_time"] = ms_to_utc(raw["close_ms"])
    return normalize(raw, CANDLE_COLUMNS)


def raw_candles_to_rows(data: list[list[str]], is_swap: bool) -> list[list]:
    """OKX 原始 K 线接口的返回 → ccxt 格式的行，只保留交易所确认已收盘的（confirm == "1"）。

    成交量取币的数量：现货是第 6 列，永续是第 7 列（与 ccxt 的做法一致）。
    """
    vol_idx = 6 if is_swap else 5
    rows = [
        [int(r[0]), float(r[1]), float(r[2]), float(r[3]), float(r[4]), float(r[vol_idx])]
        for r in data
        if r[8] == "1"
    ]
    return sorted(rows, key=lambda x: x[0])
```

`bitquant/data/quality.py`：

```python
"""数据质量检查：缺失的小时、重复、价格不合理（设计文档 7.2）。缺口只记录，不自动补。"""

from __future__ import annotations

import json
from pathlib import Path

import numpy as np
import pandas as pd

FUNDING_INTERVAL = pd.Timedelta(hours=8)
PRICE_COLUMNS = ["open", "high", "low", "close"]


def _iso(ts: pd.Timestamp) -> str:
    return ts.strftime("%Y-%m-%d %H:%M")


def find_gaps(times: pd.Series, step: pd.Timedelta) -> list[dict]:
    """中间至少少了一条记录的地方（相邻两条的间隔 ≥ 2 个 step）。"""
    t = times.sort_values().reset_index(drop=True)
    diffs = t.diff()
    gaps = [
        {"after": _iso(t[i - 1]), "before": _iso(t[i]), "missing": int(diffs[i] / step) - 1}
        for i in diffs[diffs > step].index
    ]
    return [g for g in gaps if g["missing"] >= 1]


def find_off_schedule(times: pd.Series, interval: pd.Timedelta) -> list[str]:
    """不在正常结算整点（UTC 0/8/16 点整）上的记录。10-12 实测 OKX 历史上真有：2022-12-18 18:54。"""
    off = times[times != times.dt.floor(interval)]
    return [ts.strftime("%Y-%m-%d %H:%M:%S") for ts in off]


def find_duplicates(times: pd.Series) -> list[str]:
    return [_iso(t) for t in times[times.duplicated()]]


def find_bad_prices(df: pd.DataFrame) -> list[str]:
    o, h, l, c = (df[col] for col in PRICE_COLUMNS)
    bad = (
        (l > np.minimum(o, c))
        | (h < np.maximum(o, c))
        | (df[PRICE_COLUMNS] <= 0).any(axis=1)
        | df[PRICE_COLUMNS].isna().any(axis=1)
        | (df["volume"] < 0)
    )
    return [_iso(t) for t in df.loc[bad, "close_time"]]


def candle_report(symbol: str, df: pd.DataFrame) -> dict:
    report = {"symbol": symbol, "rows": int(len(df))}
    if df.empty:
        return report | {"start": None, "end": None, "gaps": [], "missing_hours": 0, "duplicates": [], "bad_prices": []}
    gaps = find_gaps(df["close_time"], pd.Timedelta(hours=1))
    return report | {
        "start": _iso(df["close_time"].min()),
        "end": _iso(df["close_time"].max()),
        "gaps": gaps,
        "missing_hours": sum(g["missing"] for g in gaps),
        "duplicates": find_duplicates(df["close_time"]),
        "bad_prices": find_bad_prices(df),
    }


def funding_report(symbol: str, df: pd.DataFrame, history_start: pd.Timestamp) -> dict:
    """资金费率报告。starts_late=True 表示数据起点比 history_start 晚了一次结算以上。"""
    report = {"symbol": symbol, "rows": int(len(df))}
    if df.empty:
        return report | {"start": None, "end": None, "gaps": [], "off_schedule": [], "starts_late": True}
    start = df["funding_time"].min()
    return report | {
        "start": _iso(start),
        "end": _iso(df["funding_time"].max()),
        "gaps": find_gaps(df["funding_time"], FUNDING_INTERVAL),
        "off_schedule": find_off_schedule(df["funding_time"], FUNDING_INTERVAL),
        "starts_late": bool(start > history_start + FUNDING_INTERVAL),
    }


def write_report(report: dict, path: str | Path) -> None:
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(json.dumps(report, ensure_ascii=False, indent=2), encoding="utf-8")
```

```python
class FakeOhlcvClient:
    """按 since/limit 返回 [开盘时间, 开, 高, 低, 收, 量]，模拟 ccxt 的 fetch_ohlcv。"""

    def __init__(self, first_open, last_open, holes=(), fail_after=None):
        missing = set(holes)
        self.opens = [t for t in range(first_open, last_open + 1, HOUR_MS) if t not in missing]
        self.calls = 0
        self.fail_after = fail_after

    def fetch_ohlcv(self, symbol, timeframe, since=None, limit=None):
        self.calls += 1
        if self.fail_after is not None and self.calls > self.fail_after:
            raise ccxt.NetworkError("模拟断网")
        end = since + limit * HOUR_MS
        return [[t, 1.0, 2.0, 0.5, 1.5, 3.0] for t in self.opens if since <= t < end]


def hours_of(df):
    return ((df["close_time"] - pd.Timestamp("2022-03-01", tz="UTC")) / pd.Timedelta(hours=1)).astype(int).tolist()
```

```python
"""历史 K 线下载：分页、增量、断点续传（设计文档 7.2）。"""

from __future__ import annotations

from pathlib import Path
from typing import Callable

import pandas as pd

from bitquant.data.candles import ohlcv_to_frame
from bitquant.data.store import CANDLE_COLUMNS, candles_path, empty_frame, merge_frames, read_frame, write_atomic
from bitquant.timeutil import HOUR_MS, to_ms

PAGE_LIMIT = 300  # OKX K 线接口每页最多 300 根（10-12 实测）


def download_candles(
    client,
    symbol: str,
    start_open_ms: int,
    end_ms: int,
    on_page: Callable[[pd.DataFrame], None] | None = None,
    page_limit: int = PAGE_LIMIT,
) -> pd.DataFrame:
    """拉取开盘时间 ≥ start_open_ms、收盘时间 ≤ end_ms 的全部 1 小时 K 线。

    每拉到一页就调用 on_page（用来边下边存，断网时已下载的部分不丢）。
    """
    pages = []
    cursor = start_open_ms
    while cursor + HOUR_MS <= end_ms:
        rows = client.fetch_ohlcv(symbol, "1h", since=cursor, limit=page_limit)
        page = ohlcv_to_frame(rows, now_ms=end_ms)
        if page.empty:
            cursor += page_limit * HOUR_MS  # 这一段没有数据（维护或上市前），整段跳过
            continue
        pages.append(page)
        if on_page is not None:
            on_page(page)
        # 下一根的开盘时间 = 这一页最后一根的收盘时间
        cursor = max(cursor + HOUR_MS, to_ms(page["close_time"].iloc[-1]))
    if not pages:
        return empty_frame(CANDLE_COLUMNS)
    return merge_frames(empty_frame(CANDLE_COLUMNS), pd.concat(pages, ignore_index=True), CANDLE_COLUMNS)


def sync_candles(client, symbol: str, data_dir: str | Path, history_start_ms: int, end_ms: int) -> pd.DataFrame:
    """增量同步一个品种：从本地最后一根接着下；本地没有就从 history_start 开始。"""
    path = candles_path(data_dir, symbol)
    stored = read_frame(path, CANDLE_COLUMNS)
    start = history_start_ms if stored.empty else to_ms(stored["close_time"].iloc[-1])
    state = {"df": stored}

    def save(page: pd.DataFrame) -> None:
        state["df"] = merge_frames(state["df"], page, CANDLE_COLUMNS)
        write_atomic(state["df"], path)

    download_candles(client, symbol, start, end_ms, on_page=save)
    return state["df"]
```

```python
def make_zip(records, inst="BTC-USDT-SWAP"):
    buf = io.BytesIO()
    with zipfile.ZipFile(buf, "w") as zf:
        lines = ["instrument_name,funding_rate,funding_time"] + [f"{inst},{rate},{t}" for t, rate in records]
```

```python
"""资金费率（设计文档 7.2）。

两个来源（10-12 实测，重叠部分数值完全一致）：
1. 接口 /api/v5/public/funding-rate-history：只能拉最近约 3 个月，从新往旧翻页；
2. 官网历史数据 /api/v5/public/market-data-history（module=3）：2022-03 起的月度 CSV 压缩包，
   一次查询的起止间隔不能超过 10 个月。
"""

from __future__ import annotations

import io
import zipfile
from pathlib import Path
from typing import Callable

import pandas as pd

from bitquant.data.store import FUNDING_COLUMNS, empty_frame, funding_path, merge_frames, read_frame, write_atomic
from bitquant.symbols import inst_family, inst_id
from bitquant.timeutil import DAY_MS, ms_to_utc, to_ms

API_PAGE_LIMIT = 100
API_WINDOW_MS = 90 * DAY_MS          # 接口大约能覆盖的范围（保守取 90 天）
FILE_LIST_WINDOW_MS = 270 * DAY_MS   # 文件列表按 9 个月一段查（接口上限 10 个月）


def funding_frame(rows: list[tuple[int, float]]) -> pd.DataFrame:
    if not rows:
        return empty_frame(FUNDING_COLUMNS)
    df = pd.DataFrame(rows, columns=["ms", "rate"])
    df["funding_time"] = ms_to_utc(df["ms"])
    return merge_frames(empty_frame(FUNDING_COLUMNS), df, FUNDING_COLUMNS)


def fetch_funding_api(client, symbol: str, page_limit: int = API_PAGE_LIMIT) -> pd.DataFrame:
    """从最新一条往回翻页（after = 上一页最早的时间），直到接口没有更多数据。"""
    rows = []
    after = None
    while True:
        params = {"instId": inst_id(symbol), "limit": str(page_limit)}
        if after is not None:
            params["after"] = str(after)
        data = client.publicGetPublicFundingRateHistory(params).get("data") or []
        if not data:
            break
        rows += [(int(r["fundingTime"]), float(r.get("realizedRate") or r["fundingRate"])) for r in data]
        oldest = min(int(r["fundingTime"]) for r in data)
        if after is not None and oldest >= after:
            break  # 接口异常时防止死循环
        after = oldest
    return funding_frame(rows)


def list_funding_files(client, symbol: str, begin_ms: int, end_ms: int) -> list[dict]:
    """官网月度资金费率文件的列表：[{"filename": ..., "url": ...}]，按文件名排序、去重。"""
    files = {}
    start = begin_ms
    while start < end_ms:
        stop = min(start + FILE_LIST_WINDOW_MS, end_ms)
        resp = client.publicGetPublicMarketDataHistory(
            {
                "module": "3",
                "instType": "SWAP",
                "instFamilyList": inst_family(symbol),
                "dateAggrType": "monthly",
                "begin": str(start),
                "end": str(stop),
            }
        )
        for block in resp.get("data") or []:
            for detail in block.get("details") or []:
                for g in detail.get("groupDetails") or []:
                    files[g["filename"]] = g["url"]
        start = stop
    return [{"filename": name, "url": url} for name, url in sorted(files.items())]


def parse_funding_zip(content: bytes, symbol: str) -> pd.DataFrame:
    """月度文件：zip 里一个 CSV，列为 instrument_name,funding_rate,funding_time（毫秒）。"""
    rows = []
    with zipfile.ZipFile(io.BytesIO(content)) as zf:
        for name in zf.namelist():
            if not name.endswith(".csv"):
                continue
            df = pd.read_csv(zf.open(name))
            df = df[df["instrument_name"] == inst_id(symbol)]
            rows += list(zip(df["funding_time"].astype("int64"), df["funding_rate"].astype("float64")))
    return funding_frame(rows)


def download_funding_files(client, symbol: str, begin_ms: int, end_ms: int, http_get: Callable[[str], bytes]) -> pd.DataFrame:
    result = empty_frame(FUNDING_COLUMNS)
    for f in list_funding_files(client, symbol, begin_ms, end_ms):
        result = merge_frames(result, parse_funding_zip(http_get(f["url"]), symbol), FUNDING_COLUMNS)
    return result


def sync_funding(
    client,
    symbol: str,
    data_dir: str | Path,
    history_start_ms: int,
    end_ms: int,
    http_get: Callable[[str], bytes],
) -> pd.DataFrame:
    """增量同步一个永续品种的资金费率。

    本地没有数据，或本地最后一条已超出接口能覆盖的范围时，先用官网月度文件补齐；
    然后总是用接口拉最近约 3 个月，合并去重。早于 history_start 的记录丢掉。
    """
    path = funding_path(data_dir, symbol)
    merged = read_frame(path, FUNDING_COLUMNS)
    if merged.empty:
        files_from = history_start_ms
    else:
        last = to_ms(merged["funding_time"].iloc[-1])
        files_from = last if end_ms - last > API_WINDOW_MS else None
    if files_from is not None:
        merged = merge_frames(merged, download_funding_files(client, symbol, files_from, end_ms, http_get), FUNDING_COLUMNS)
    merged = merge_frames(merged, fetch_funding_api(client, symbol), FUNDING_COLUMNS)
    start = pd.Timestamp(history_start_ms, unit="ms", tz="UTC")
    merged = merged[merged["funding_time"] >= start].reset_index(drop=True)
    write_atomic(merged, path)
    return merged
```

```python
"""实时更新：整点后取回刚收盘的 K 线（设计文档 7.2；阶段 3 的模拟盘驱动直接复用）。"""

from __future__ import annotations

import time
from pathlib import Path
from typing import Callable

import pandas as pd

from bitquant.data.candles import ohlcv_to_frame, raw_candles_to_rows
from bitquant.data.store import CANDLE_COLUMNS, candles_path, merge_frames, read_frame, write_atomic
from bitquant.symbols import inst_id, is_swap
from bitquant.timeutil import now_ms, to_ms

RECENT_LIMIT = 5


def fetch_recent_closed(client, symbol: str, now: int) -> pd.DataFrame:
    """最近几根已收盘的 K 线。用原始接口，按交易所的 confirm 标记判断是否已收盘。"""
    resp = client.publicGetMarketCandles({"instId": inst_id(symbol), "bar": "1H", "limit": str(RECENT_LIMIT)})
    return ohlcv_to_frame(raw_candles_to_rows(resp.get("data") or [], is_swap(symbol)), now_ms=now)


def wait_for_bar(
    client,
    symbol: str,
    expected_close_ms: int,
    *,
    clock: Callable[[], int] = now_ms,
    sleep: Callable[[float], None] = time.sleep,
    max_wait_s: float = 60,
    retry_every_s: float = 5,
) -> pd.DataFrame | None:
    """等收盘时间为 expected_close_ms 的那根 K 线出来；最多等 max_wait_s 秒，等不到返回 None。"""
    deadline = clock() + int(max_wait_s * 1000)
    expected = pd.Timestamp(expected_close_ms, unit="ms", tz="UTC")
    while True:
        frame = fetch_recent_closed(client, symbol, clock())
        if not frame.empty and to_ms(frame["close_time"].iloc[-1]) >= expected_close_ms:
            return frame[frame["close_time"] <= expected].reset_index(drop=True)
        if clock() >= deadline:
            return None
        sleep(retry_every_s)


def update_latest(client, symbol: str, data_dir: str | Path, expected_close_ms: int, **wait_kwargs) -> bool:
    """把刚收盘的 K 线追加到本地。等不到返回 False，由调用方记日志并跳过这个小时。"""
    frame = wait_for_bar(client, symbol, expected_close_ms, **wait_kwargs)
    if frame is None:
        return False
    path = candles_path(data_dir, symbol)
    write_atomic(merge_frames(read_frame(path, CANDLE_COLUMNS), frame, CANDLE_COLUMNS), path)
    return True
```

```python
        write_report(report, data_dir / "quality" / f"{file_stem(symbol)}.json")
```

```python
"""OKX 执行器（阶段 1 部分）：查持仓、下单、按订单编号查单、撤单（设计文档 7.1、7.2）。

对外数量一律是币的数量；永续的"张"只在这里换算。
execute()（含重试和防止重复下单）在阶段 3 实现。
"""

from __future__ import annotations

from decimal import Decimal

import ccxt
import pandas as pd

from bitquant.models import Fill, MarketRule, Order
from bitquant.symbols import base_ccy


def _d(x) -> Decimal:
    return Decimal(str(x))


class OkxBroker:
    def __init__(self, client, rules: dict[str, MarketRule]):
        self.client = client
        self.rules = rules

    def to_exchange_amount(self, symbol: str, qty: float) -> float:
        """币的数量 → 交易所的下单数量（现货是币，永续是张）；不合规的数量在发单前就拒绝。"""
        rule = self.rules[symbol]
        if qty < rule.min_amount:
            raise ValueError(f"{symbol} 数量 {qty} 小于最小下单量 {rule.min_amount}")
        steps = _d(qty) / _d(rule.amount_step)
        if steps != steps.to_integral_value():
            raise ValueError(f"{symbol} 数量 {qty} 不是步长 {rule.amount_step} 的整数倍")
        if rule.kind == "spot":
            return float(qty)
        return float(_d(qty) / _d(rule.contract_size))

    def _params(self, order: Order) -> dict:
        params = {"clientOrderId": order.client_id}
        if self.rules[order.symbol].kind == "swap":
            params["marginMode"] = "isolated"  # 永续逐仓；现货由 ccxt 自动用 cash 模式
        return params

    def place_market(self, order: Order) -> dict:
        amount = self.to_exchange_amount(order.symbol, order.qty)
        return self.client.create_order(order.symbol, "market", order.side, amount, None, self._params(order))

    def place_limit(self, order: Order, price: float) -> dict:
        amount = self.to_exchange_amount(order.symbol, order.qty)
        return self.client.create_order(order.symbol, "limit", order.side, amount, price, self._params(order))

    def fetch_by_client_id(self, symbol: str, client_id: str) -> dict | None:
        try:
            return self.client.fetch_order(None, symbol, {"clientOrderId": client_id})
        except ccxt.OrderNotFound:
            return None

    def cancel(self, symbol: str, client_id: str) -> dict:
        return self.client.cancel_order(None, symbol, {"clientOrderId": client_id})

    def positions(self) -> dict[str, float]:
        """当前持仓（币的数量，空头为负）：现货 = 该币总余额；永续 = 净持仓张数 × 合约面值。"""
        out: dict[str, float] = {}
        spots = [s for s, r in self.rules.items() if r.kind == "spot"]
        swaps = [s for s, r in self.rules.items() if r.kind == "swap"]
        if spots:
            balance = self.client.fetch_balance()
            for s in spots:
                out[s] = float((balance.get(base_ccy(s)) or {}).get("total") or 0.0)
        if swaps:
            for s in swaps:
                out[s] = 0.0
            for p in self.client.fetch_positions(swaps):
                s = p.get("symbol")
                if s in swaps:
                    pos = (p.get("info") or {}).get("pos") or "0"
                    out[s] = float(_d(out[s]) + _d(pos) * _d(self.rules[s].contract_size))
        return out

    def fill_from_order(self, order: dict) -> Fill:
        """ccxt 订单 → 成交记录：数量换成币，手续费折成 USDT。"""
        symbol = order["symbol"]
        rule = self.rules[symbol]
        filled = order.get("filled") or 0.0
        qty = float(filled) if rule.kind == "spot" else float(_d(filled) * _d(rule.contract_size))
        price = float(order.get("average") or 0.0)
        fee = order.get("fee") or {}
        cost = float(fee.get("cost") or 0.0)
        fee_usdt = cost * price if fee.get("currency") == base_ccy(symbol) else cost
        ts = pd.Timestamp(order.get("lastTradeTimestamp") or order.get("timestamp"), unit="ms", tz="UTC")
        return Fill(order.get("clientOrderId") or "", symbol, order["side"], qty, price, fee_usdt, ts)
```

```python
"""模拟盘账户初始化和下单验证用到的纯函数（脚本见 scripts/init_demo_account.py、scripts/okx_smoke.py）。"""

from __future__ import annotations

from decimal import Decimal

from bitquant.exchange.rules import floor_to_step
from bitquant.models import MarketRule, Order, client_order_id
from bitquant.symbols import base_ccy


def liquidation_orders(balances: dict[str, float], rules: dict[str, MarketRule], signal_time) -> tuple[list[Order], list[str]]:
    """把模拟盘赠送的现货币全部卖成 USDT 的订单；不足最小下单量的余额（粉尘）跳过并给出说明。"""
    orders, skipped = [], []
    for symbol, rule in sorted(rules.items()):
        if rule.kind != "spot":
            continue
        held = balances.get(base_ccy(symbol), 0.0)
        qty = floor_to_step(held, rule.amount_step)
        if qty < rule.min_amount:
            if held > 0:
                skipped.append(f"{symbol} 余额 {held} 小于最小下单量 {rule.min_amount}，跳过")
            continue
        orders.append(Order(client_order_id("init", symbol, signal_time), symbol, "sell", qty, signal_time))
    return orders, skipped


def smoke_qty(rule: MarketRule) -> float:
    """验证用的下单数量：现货取最小下单量的 10 倍（扣掉以币计的手续费后还能卖回去），永续取最小下单量。"""
    return float(Decimal(str(rule.min_amount)) * (10 if rule.kind == "spot" else 1))


def sellable_after_fee(filled_qty: float, fee_cost: float, fee_ccy: str | None, base: str, step: float) -> float:
    """现货买入后实际到账 = 成交数量 − 以币计的手续费，再向下取整到步长。"""
    net = Decimal(str(filled_qty)) - (Decimal(str(fee_cost)) if fee_ccy == base else Decimal(0))
    return floor_to_step(float(net), step)


def far_limit_price(bid: float, tick: float, discount: float = 0.2) -> float:
    """远离市价、不会成交的限价买单价格：买一价打八折，向下取整到价格步长。"""
    return floor_to_step(float(Decimal(str(bid)) * (1 - Decimal(str(discount)))), tick)
```

```python
"""模拟盘账户初始化（拿到模拟盘密钥后执行一次）：python -m scripts.init_demo_account

1. 账户模式切到"合约模式"（acctLv=2），持仓模式设为单向持仓（net_mode）；
2. 永续设为逐仓 3 倍；
3. 把模拟盘赠送的 BTC、ETH 卖成 USDT，让交易所持仓 = 策略持仓。
"""

from __future__ import annotations

from pathlib import Path

import pandas as pd
from dotenv import load_dotenv

from bitquant.broker.demo import liquidation_orders
from bitquant.broker.okx import OkxBroker
from bitquant.config import load_credentials, load_settings
from bitquant.exchange.okx import make_trading_client
from bitquant.exchange.rules import fetch_and_save_rules
from bitquant.symbols import base_ccy

LEVERAGE = 3
FUTURES_MODE = "2"


def main() -> int:
    settings = load_settings()
    load_dotenv(Path("config/.env"))
    client = make_trading_client(settings, load_credentials(settings.mode))
    rules = fetch_and_save_rules(client, settings.symbols, Path(settings.data_dir) / "market_rules.json")

    config = client.privateGetAccountConfig()["data"][0]
    print(f"当前账户模式 acctLv={config.get('acctLv')}，持仓模式 posMode={config.get('posMode')}")
    if config.get("acctLv") != FUTURES_MODE:
        client.privatePostAccountSetAccountLevel({"acctLv": FUTURES_MODE})
        print("已切换到合约模式（acctLv=2）")
    if config.get("posMode") != "net_mode":
        client.set_position_mode(False)
        print("已切换到单向持仓（net_mode）")
    for symbol in settings.swap:
        client.set_leverage(LEVERAGE, symbol, {"marginMode": "isolated"})
        print(f"{symbol} 已设为逐仓 {LEVERAGE} 倍")

    broker = OkxBroker(client, rules)
    balance = client.fetch_balance()
    free = {base_ccy(s): float((balance.get(base_ccy(s)) or {}).get("free") or 0.0) for s in settings.spot}
    orders, skipped = liquidation_orders(free, rules, pd.Timestamp.now(tz="UTC").floor("h"))
    for msg in skipped:
        print(msg)
    for order in orders:
        broker.place_market(order)
        print(f"已市价卖出 {order.qty} {order.symbol}（订单编号 {order.client_id}）")
    print("初始化完成，当前持仓：", broker.positions())
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

`scripts/okx_smoke.py`：

```python
"""模拟盘下单验证（阶段 1 验收 ③）：python -m scripts.okx_smoke

需要 config/.env 里的模拟盘密钥，并且已经执行过 python -m scripts.init_demo_account。
每个品种：最小数量市价买入 → 按订单编号查成交 → 市价卖出平掉；
第一个现货品种再挂一笔远离市价的限价买单，按编号查到后撤掉。
"""

from __future__ import annotations

import time
from pathlib import Path

import pandas as pd
from dotenv import load_dotenv

from bitquant.broker.demo import far_limit_price, sellable_after_fee, smoke_qty
from bitquant.broker.okx import OkxBroker
from bitquant.config import load_credentials, load_settings
from bitquant.exchange.okx import make_market_client, make_trading_client
from bitquant.exchange.rules import fetch_and_save_rules
from bitquant.models import Order, client_order_id
from bitquant.symbols import base_ccy


def wait_closed(broker: OkxBroker, symbol: str, client_id: str, tries: int = 10, pause: float = 1.0) -> dict | None:
    for _ in range(tries):
        order = broker.fetch_by_client_id(symbol, client_id)
        if order is not None and order.get("status") == "closed":
            return order
        time.sleep(pause)
    return None


def main() -> int:
    settings = load_settings()
    load_dotenv(Path("config/.env"))
    client = make_trading_client(settings, load_credentials(settings.mode))
    market = make_market_client(settings)
    rules = fetch_and_save_rules(client, settings.symbols, Path(settings.data_dir) / "market_rules.json")
    broker = OkxBroker(client, rules)
    hour = pd.Timestamp.now(tz="UTC").floor("h")
    results: list[tuple[str, bool]] = []

    def check(name: str, ok: bool, detail: str = "") -> None:
        results.append((name, ok))
        print("通过" if ok else "失败", name, detail)

    print("当前持仓：", broker.positions())
    for symbol in settings.symbols:
        rule = rules[symbol]
        qty = smoke_qty(rule)
        buy = Order(client_order_id("smoke", symbol, hour, tag="b"), symbol, "buy", qty, hour)
        broker.place_market(buy)
        got = wait_closed(broker, symbol, buy.client_id)
        if got is None:
            check(f"{symbol} 市价买入", False, "按订单编号查不到成交")
            continue
        fill = broker.fill_from_order(got)
        check(f"{symbol} 市价买入", fill.qty > 0, f"均价 {fill.price}，数量 {fill.qty}，手续费 {fill.fee_usdt:.6f} USDT")
        fee = got.get("fee") or {}
        sell_qty = qty if rule.kind == "swap" else sellable_after_fee(
            float(got["filled"]), float(fee.get("cost") or 0.0), fee.get("currency"), base_ccy(symbol), rule.amount_step
        )
        if sell_qty < rule.min_amount:
            check(f"{symbol} 市价卖出", False, f"扣掉手续费后只剩 {sell_qty}，小于最小下单量")
            continue
        sell = Order(client_order_id("smoke", symbol, hour, tag="s"), symbol, "sell", sell_qty, hour)
        broker.place_market(sell)
        check(f"{symbol} 市价卖出", wait_closed(broker, symbol, sell.client_id) is not None)

    symbol = settings.spot[0]
    rule = rules[symbol]
    price = far_limit_price(market.fetch_ticker(symbol)["bid"], rule.price_tick)
    limit = Order(client_order_id("smoke", symbol, hour, tag="l"), symbol, "buy", smoke_qty(rule), hour)
    broker.place_limit(limit, price)
    opened = broker.fetch_by_client_id(symbol, limit.client_id)
    check("限价单挂单后按编号查到", opened is not None and opened.get("status") == "open", f"价格 {price}")
    broker.cancel(symbol, limit.client_id)
    canceled = broker.fetch_by_client_id(symbol, limit.client_id)
    check("撤单", canceled is not None and canceled.get("status") == "canceled")
    check("查不存在的编号返回空", broker.fetch_by_client_id(symbol, "smokenotexist0000") is None)

    failed = sum(1 for _, ok in results if not ok)
    print(f"\n共 {len(results)} 项，失败 {failed} 项。当前持仓：", broker.positions())
    return 1 if failed else 0


if __name__ == "__main__":
    raise SystemExit(main())
```
